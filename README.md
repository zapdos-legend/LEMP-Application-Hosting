# LEMP-Application-Hosting
Deployed a LEMP web application using EC2 and RDS on AWS with Nginx, MySQL, and PHP integration.

## 🎯 Purpose

The purpose of this project is to deploy and host a modern LEMP stack web application on AWS cloud infrastructure.

LEMP stands for:

* **Linux** – Operating System
* **Nginx** – Web Server
* **MySQL** – Database
* **PHP** – Server-side Programming Language

This project demonstrates:

* Hosting PHP web applications using Nginx
* Managing MySQL databases securely
* Deploying scalable cloud-based web applications
* Configuring modern high-performance web hosting infrastructure

The LEMP stack provides faster and lightweight web hosting compared to traditional setups.

## 🧰 AWS Services Used

* **Amazon EC2** – Used for hosting the Linux server, Nginx web server, and PHP application.
* **Amazon RDS** – Used for managing the MySQL relational database securely.
